## 🎯 Overview

Generate a personalised, phase-specific piercing aftercare schedule. Enter your piercing date for a clinical routine across all three healing phases.

**Category:** Client Health & Aftercare

This is a free, open-source widget from the [Poli International Widget Suite](https://poliinternational.com/tools/) - a collection of practical tools for tattoo and piercing studios, artists, and clients. It runs entirely in the browser; no data is sent to a server.

---

## ✨ Features

- ✅ **Piercing Aftercare Schedule**
- ✅ **How To Clean A Piercing**
- ✅ **Aftercare Routine Piercing**
- ✅ **Piercing Healing Phases**
- ✅ **Saline Solution Piercing**
- ✅ **BioFlex Aftercare**
- ✅ **Responsive Design** - works on desktop, tablet, and mobile.
- ✅ **Free & Open Source** - MIT licensed.

## 🚀 Installation

### Option 1: Use Online (Recommended)

No installation needed! Just visit:
**[https://poliinternational.com/tools/aftercare-schedule-generator/](https://poliinternational.com/tools/aftercare-schedule-generator/)**

### Option 2: Run Locally

This tool is pure HTML/CSS/JS - no build step. Clone the repo and open `index.html`:

```bash
git clone https://github.com/Poli-International/aftercare-schedule-generator.git
cd aftercare-schedule-generator
# open index.html in your browser
```
