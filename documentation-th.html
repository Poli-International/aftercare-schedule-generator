แผนดูแลหลังเจาะที่พิมพ์ได้ พร้อมวันที่จริง: แผลอยู่ในระยะการหายระยะใด ควรทำและหลีกเลี่ยงอะไรในระยะนั้น เมื่อใดควรลดขนาดเครื่องประดับ และเมื่อใดแผลควรหายสนิท

01วิธีใช้งาน

  1. เลือกประเภทการเจาะ (ติ่งหู, กระดูกอ่อนหู, daith / rook / snug / tragus, รูจมูก, กั้นจมูก, labret / lip / monroe, ลิ้น, สะดือ, surface / dermal, หัวนม, อวัยวะเพศ)
  2. กรอกวันที่เจาะ ใส่วันในอนาคตก็ได้: ลูกค้าที่จองไว้สัปดาห์หน้าจะได้รับแผนตั้งแต่วันแรก
  3. เลือกสภาพปัจจุบัน: ปกติ มีตุ่มเล็กน้อย แดงหรือระคายเคือง หรือมีสารคัดหลั่งผิดปกติ
  4. จะใส่ชื่อสตูดิโอและข้อมูลติดต่อก็ได้ ข้อมูลเหล่านี้จะปรากฏบนกระดาษที่พิมพ์
  5. กดสร้างตารางดูแลหลังเจาะของฉัน จากนั้นกดพิมพ์ / บันทึกเป็น PDF เพื่อมอบกระดาษให้ลูกค้า หรือกดเพิ่มลงปฏิทิน เพื่อดาวน์โหลดไฟล์ปฏิทินที่มีการเตือนความจำ

02ระยะการหายทั้งสามระยะ

แต่ละตำแหน่งมีระยะเวลาของตัวเอง เครื่องมือจะนับจำนวนวันตั้งแต่วันที่เจาะและจัดให้อยู่ในระยะหนึ่ง:

ตำแหน่งระยะที่ 1 สิ้นสุดระยะที่ 2 สิ้นสุดคาดว่าหายสนิทการล้างด้วยน้ำเกลือในระยะที่ 1
ติ่งหูวันที่ 21วันที่ 90วันที่ 180วันละสองครั้ง
กระดูกอ่อนหู (helix / flat)วันที่ 42วันที่ 180วันที่ 365วันละสองครั้ง
Daith / rook / snug / tragusวันที่ 42วันที่ 180วันที่ 365วันละสองครั้ง
รูจมูกวันที่ 42วันที่ 120วันที่ 180วันละสองครั้ง
กั้นจมูก (septum)วันที่ 42วันที่ 90วันที่ 180วันละสองครั้ง
Labret / lip / monroeวันที่ 42วันที่ 90วันที่ 180วันละสองครั้ง พร้อมการบ้วนปาก
ลิ้นวันที่ 21วันที่ 56วันที่ 120วันละสามครั้ง พร้อมการบ้วนปาก
สะดือวันที่ 56วันที่ 180วันที่ 365วันละสองครั้ง
Surface / dermalวันที่ 56วันที่ 180วันที่ 365วันละครั้ง
หัวนมวันที่ 90วันที่ 180วันที่ 365วันละสองครั้ง
อวัยวะเพศ (ทั่วไป)วันที่ 42วันที่ 120วันที่ 365วันละสองครั้ง
  • ระยะที่ 1 เฉียบพลัน / อักเสบ: ล้างแผลด้วยน้ำเกลือปลอดเชื้อ (สารละลายโซเดียมคลอไรด์ 0.9% ไม่มีส่วนผสมอื่น) ปล่อยเครื่องประดับให้อยู่นิ่งสนิท ห้ามใช้สบู่ สเปรย์ฆ่าเชื้อ ไฮโดรเจนเปอร์ออกไซด์ น้ำมันทีทรี หรือแอลกอฮอล์ ห้ามว่ายน้ำ
  • ระยะที่ 2 การสร้างเนื้อเยื่อใหม่ / การซ่อมแซม: ล้างวันละหนึ่งหรือสองครั้ง ยังไม่เปลี่ยนเครื่องประดับ ห้ามแช่ในสระว่ายน้ำ อ่างน้ำร้อน หรือแหล่งน้ำเปิด
  • ระยะที่ 3 การปรับโครงสร้าง / การเติบโตเต็มที่: ล้างสัปดาห์ละหนึ่งหรือสองครั้ง อาบน้ำล้างตามปกติ ใช้วัสดุเกรดปลูกฝัง (implant-grade) เฉพาะเมื่อเปลี่ยนเครื่องประดับ

ตำแหน่งในช่องปาก (labret / lip / monroe, ลิ้น) มีขั้นตอนการบ้วนปากเพิ่มเติมในทุกระยะ

03การลดขนาด

แท่งเครื่องประดับชิ้นแรกจะใส่ให้ยาวเพื่อเว้นที่สำหรับอาการบวม เครื่องมือจะกำหนดวันลดขนาดไว้ที่สิ้นสุดระยะที่ 1 เมื่ออาการบวมลดลงแล้ว: วันที่ 21 สำหรับลิ้น วันที่ 90 สำหรับหัวนม วันที่นี้คำนวณจากตารางเดียวกัน จึงไม่มีทางขัดแย้งกับระยะต่าง ๆ

04สภาพปัจจุบัน

เมื่อเลือกสภาพอื่นที่ไม่ใช่ปกติ แผนจะเพิ่มคำอธิบายสั้น ๆ ได้แก่ ตุ่มระคายเคืองและสาเหตุทั่วไป (แรงกด การเกี่ยวติด เครื่องประดับที่ใส่ไม่พอดี) เมื่อใดที่คาดว่าจะมีรอยแดง และเมื่อใดที่บ่งชี้การบาดเจ็บหรือผลิตภัณฑ์ใหม่ และสะเก็ดน้ำเหลืองปกติต่างจากสารคัดหลั่งสีเหลือง เขียว หรือมีกลิ่นเหม็นอย่างไร

เครื่องมือนี้ให้คำแนะนำการดูแลหลังเจาะทั่วไป ไม่ใช่การวินิจฉัย การหายของแผลแตกต่างกันในแต่ละคน หากมีสัญญาณของการติดเชื้อ เช่น รอยแดงที่ลามออก มีไข้ มีหนอง หรือบวมมาก ลูกค้าควรไปพบแพทย์โดยเร็ว และให้ถอดเครื่องประดับออกเฉพาะตามคำแนะนำของผู้เชี่ยวชาญเท่านั้น

05ไฟล์ปฏิทิน

เพิ่มลงปฏิทิน จะดาวน์โหลดไฟล์ .ics มาตรฐานที่แอปปฏิทินใดก็นำเข้าได้ ประกอบด้วยการเตือนการทำความสะอาด จุดเริ่มต้นของระยะที่ 2 และ 3 และวันลดขนาด

06ภาษาและความเป็นส่วนตัว

เครื่องมือนี้ใช้งานได้ในภาษาอังกฤษ ฝรั่งเศส เยอรมัน อิตาลี สเปน ดัตช์ และโปรตุเกส ทุกการคำนวณทำในเบราว์เซอร์: ข้อมูลที่กรอกจะไม่ถูกส่งไปที่ใด และจะไม่มีการจัดเก็บ
